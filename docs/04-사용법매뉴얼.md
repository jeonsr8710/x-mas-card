# 🎄 X-mas Card Studio — 사용법 매뉴얼

이 문서는 **크리스마스 온라인 카드**를 만들고, 이메일·카카오톡·SMS·개인화 링크로 보내며, 열람 현황과 답장을 확인하는 실사용 안내서입니다.

---

## 1. 프로그램 실행

1. 바탕화면의 **`크리스마스 카드`** 아이콘을 더블클릭합니다. (웹 주소: `http://localhost:3000`)
2. 상단 메뉴에서 **[발송 설정]**(이메일·카카오·SMS·공유 주소 등록)과 **[사용 매뉴얼]** 을 언제든 열 수 있습니다.

---

## 2. 카드 만들기

1. **디자인 테마 선택**: 4가지 테마 중 하나를 고릅니다.
   - `클래식 홀리데이` / `고요한 눈 내리는 밤` / `따뜻한 겨울 오두막` / `미니멀 골드 리스`
2. **추천 인사말 또는 직접 작성**:
   - `친구 · 지인`, `가족 · 연인`, `직장 · 비즈니스` 프리셋 버튼으로 문구를 빠르게 채우거나 직접 수정합니다.
   - 보내는 분 이름, 카드 제목, 메시지를 입력합니다.
3. **이미지 첨부 (선택)**:
   - 기본 제공 샘플 4종(`트리`, `눈사람`, `벽난로`, `산타`) 중 선택하거나 내 PC 사진 파일을 업로드합니다.
4. **배경음악(오르골 캐롤) 선택**:
   - `징글벨`, `고요한 밤 거룩한 밤`, `We Wish You a Merry Christmas`, `배경음악 없음` 중 선택합니다.
5. **실시간 미리보기 확인 후 저장**:
   - 오른쪽(PC) 실시간 미리보기에서 **봉투 / 열린 카드**를 전환해 확인한 뒤 **`카드 저장하고 보내기`** 를 클릭합니다.

---

## 3. 만든 카드 관리 · 삭제 (화면 하단)

- 첫 화면 맨 아래 **`만든 카드 목록`** 에서 DB에 저장된 기존 카드를 바로 다시 열어 관리할 수 있습니다.
- 체크박스로 여러 카드를 선택해 **`선택 삭제`** 하거나, 각 카드 우측 휴지통 아이콘으로 개별 삭제할 수 있습니다.

---

## 4. 채널별 발송 방법 (`/manage/[manageToken]`)

카드 저장 후 이동하는 관리 화면에서 4개 탭으로 발송합니다.

### ① 이메일 발송
- 최초 1회 **[발송 설정] → [이메일]** 에서 Gmail(`앱 비밀번호 16자리`), 네이버 메일(SMTP), 또는 Resend API 키를 저장합니다.
- 수신자 이름과 이메일을 1명 이상(최대 30명) 입력하고 발송하면, 인라인 카드 이미지와 **`✨ 온라인카드 열어보기`** 버튼이 담긴 HTML 메일이 발송됩니다.
- *(설정 전에는 실제 발송 대신 HTML 렌더링 미리보기가 생성됩니다.)*

### ② 카카오톡 공유
- **JavaScript 키 등록 시**: 받는 분 이름을 입력하고 **`카카오톡으로 공유하기`** 를 누르면 카톡 친구/채팅방 선택 창이 열립니다.
- **키가 없어도 가능**: **`카톡 공유 문구 & QR 생성`** 으로 생성된 문구를 **`카톡 전송용 문구 복사`** 해서 카톡 창에 붙여넣어 보낼 수 있습니다.

### ③ SMS 문자 발송
- **방법 A — 무료 스마트폰 QR 방식**: **`스마트폰 QR · 문자 앱 링크 생성 (무료)`** 클릭 → 화면의 QR을 내 휴대폰 카메라로 스캔하면 문자 앱이 수신 번호와 카드 링크가 채워진 상태로 바로 열립니다.
- **방법 B — PC 직접 API 발송 (Solapi)**: `[발송 설정] → [SMS 문자]`에 Solapi 키와 사전 등록된 발신번호를 입력하면 PC에서 버튼 한 번으로 실제 SMS/LMS가 발송됩니다. *(건당 요금 발생)*

### ④ 개인화 링크 복사
- 이메일·카톡·문자 없이 링크만 직접 전달하고 싶을 때 받는 분 이름을 입력하면, 카드 봉투에 `To. OOO님`이 표시되고 열람 횟수가 개별 추적되는 전용 링크와 QR이 생성됩니다.

---

## 5. 외부 지인 발송 시 주의사항 & 수신자 답장 확인

- **공유 주소(Base URL)**: 내 컴퓨터 주소(`localhost:3000`) 그대로 보내면 외부 지인이 열 수 없습니다. Vercel 배포 주소(`https://...vercel.app`) 등을 **[발송 설정] → [공유 주소]** 에 등록해 두면 내 PC를 꺼두어도 지인이 24시간 카드를 열 수 있습니다.
- **열람 · 답장 확인**: 지인이 카드를 열거나 답장(이모지 + 메시지)을 남기면 관리 화면 하단 **발송 및 열람 현황**과 **받은 답장** 목록에 실시간 반영됩니다.
