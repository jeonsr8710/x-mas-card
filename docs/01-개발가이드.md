# 🎄 X-mas Card Studio — 동일 프로그램 제작 · 개발 가이드

이 문서는 **X-mas Card Studio**와 동일한 구조의 온라인 카드 제작·발송 웹 애플리케이션(예: 연하장, 청첩장, 감사인사, 어버이날, 생일 카드 등)을 새로 만들거나 복제 개발할 때 필요한 기준 가이드입니다.

## 2. 프로젝트 복제 및 초기 분리 원칙

기존 `X-mas` 코드와 운영 데이터에 영향을 주지 않도록 새 폴더를 만들 때 아래 5가지를 반드시 분리합니다.

1. **포트 분리**: `X-mas`가 `3000` 포트를 사용하므로, 새 앱은 `3011`, `3020` 등 겹치지 않는 포트로 `package.json`(`dev`, `start`)과 `launch.sh`를 설정합니다.
2. **런타임 파일 분리**: `launch.sh`의 `/tmp/*.port`, `/tmp/*.pid`, `/tmp/*.buildid`, `/tmp/*.log` 접두사를 프로젝트별로 다르게 지정합니다.
3. **로컬 설정 파일 분리**: `src/lib/settings.ts`의 `LOCAL_SETTINGS_PATH` 파일명을 프로젝트 고유 이름(예: `.newcard-settings.local.json`)으로 바꾸고 `.gitignore`에 등록합니다.
4. **DB 완전 분리**: 로컬 SQLite(`file:./dev.db`)나 별도 Neon PostgreSQL 프로젝트를 연결해 카드·발송 이력이 섞이지 않게 합니다.
5. **GitHub · Vercel · 카카오 앱 분리**:
   - 새 GitHub 저장소 생성 후 `git init -b main` → 푸시
   - Vercel 프로젝트 Import 시 `DATABASE_URL` 및 `PUBLIC_VIEWER_ONLY="true"` 설정
   - 카카오톡 말풍선 출처 이름/링크 도메인을 분리하려면 카카오 디벨로퍼스에서 **새 애플리케이션**을 생성하고 `JavaScript SDK 도메인`과 `제품 링크 관리 → 웹 도메인`을 모두 등록

## 3. 새 카드 프로그램 제작 시 커스터마이징 체크리스트

기존 재사용 모듈(`prisma.ts`, `mode.ts`, `privacy.ts`, `network.ts`, `solapi.ts`, API 라우트 구조)은 그대로 두고 아래 항목만 새 테마에 맞게 교체합니다.

- **`src/lib/templates.ts`**:

  - `BGM_OPTIONS` 및 `BgmKey` (`jingle-bells`, `silent-night`, `we-wish`, `none`)

- **`src/components/CardMotif.tsx`**: 봉투/속지 상단에 들어가는 테마별 SVG 일러스트 교체

### B. 발송 문구 · 메타데이터 · OG 이미지 계층

- **`src/lib/email.ts`**: `renderChristmasEmailHtml` 배지(`MERRY CHRISTMAS` 등), 색상, 문구 수정
- **`src/app/layout.tsx` & `src/app/page.tsx`**: `<title>`, 메타 설명, 헤더 배지·제목, `PUBLIC_VIEWER_ONLY` 안내 타이틀 수정

## 4. Next.js 16 개발 시 유의사항 (핵심 함정)

1. **`cacheComponents: true` 대응**:
   - 동적 DB 조회나 `connection()`을 호출하는 Server Component(`src/app/page.tsx`, `src/app/c/[slug]/page.tsx`, `src/app/manage/[manageToken]/page.tsx`)는 반드시 `<Suspense>` 경계 내부에서 렌더링해야 `next build` 시 프리렌더 오류가 나지 않습니다.
2. **Prisma 스키마 이중화 (`scripts/prepare-prisma.mjs`)**:
   - `VERCEL === "1"`이거나 `DATABASE_URL`이 `postgres://`/`postgresql://`로 시작하면 `prisma/schema.postgres.prisma`를 `prisma/schema.prisma`로 복사합니다.
   - `prisma/schema.postgres.prisma`에는 반드시 `binaryTargets = ["native", "rhel-openssl-3.0.x"]`가 포함되어야 Vercel 서버리스 런타임에서 Prisma 엔진이 정상 동작합니다.
   - `outputFileTracingIncludes`([next.config.ts](file:///home/jeonsr/바탕화면/Project/X-mas/next.config.ts))에 `./node_modules/.prisma/client/**/*`와 `./assets/fonts/**/*`를 포함해야 Vercel 배포 시 한글 OG 폰트(`UnDinaruBold.ttf`)가 누락되지 않습니다.
3. **ESLint `react-hooks/set-state-in-effect`**:
   - `useEffect` 내부에서 동기 `setState` 호출을 피하고, `fetch(...).then(...)` 콜백 등 비동기 콜백에서만 상태를 갱신해야 `npm run lint`가 통과합니다.
