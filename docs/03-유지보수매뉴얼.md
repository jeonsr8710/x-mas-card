## 2. 로컬 실행 및 서버 프로세스 관리

- **권장 실행**: 바탕화면의 **`크리스마스 카드`** 아이콘 또는 `./launch.sh` 실행
- **자동 재기동 원리 (`launch.sh`)**:
  - `/tmp/xmas-card-studio.port`에 기록된 포트가 살아 있고 `.next/BUILD_ID`가 `/tmp/xmas-card-studio.buildid`와 같으면 기존 서버를 유지한 채 브라우저만 엽니다.
  - 빌드 후 `BUILD_ID`가 바뀌었으면 기존 PID(`/tmp/xmas-card-studio.pid`)를 종료하고 새로 `next start`를 띄웁니다.
- **로그 및 상태 파일**:
  - 서버 로그: `/tmp/xmas-card-studio.log`
  - 포트 / PID / 빌드 ID: `/tmp/xmas-card-studio.port`, `.pid`, `.buildid`
  - 포트 `3000`이 다른 앱에 점유되어 있으면 `3001~3005` 중 빈 포트를 자동 탐색합니다.

## 3. DB 백업 및 민감정보 관리

| 파일 | 역할 | 주의사항 |
|---|---|---|
| `.env` | `DATABASE_URL` 및 선택 환경변수 | Git 커밋 금지 (`.gitignore` 제외됨) |
| `.xmas-settings.local.json` | SMTP·Resend·카카오·Solapi·Base URL | 권한 `0600` 유지, Git 커밋 금지 |
| `prisma/dev.db` | (로컬 SQLite 사용 시) 카드·발송·답장 DB | 주기적 파일 복사 백업 권장 |

- **클라우드 DB(Neon PostgreSQL) 전환 시 주의**:
  - `.env`의 `DATABASE_URL`을 Neon 주소로 바꾼 뒤에는 반드시 `npm run db:push`와 `npm run build`를 순서대로 실행해야 Prisma Client가 PostgreSQL 용으로 재생성됩니다.

## 4. 자주 발생하는 문제와 해결 방법 (트러블슈팅)

### Q1. 스마트폰으로 QR 스캔 시 `404` 또는 접속 불가
- **원인**: Base URL이 `localhost`이거나, 폰과 PC가 서로 다른 네트워크(LTE/5G vs 사내 Wi-Fi)에 연결되어 있음.
- **조치**:
  1. 외부에서도 열려야 한다면 `[발송 설정] → [공유 주소]`에 Vercel 공개 주소(`https://...vercel.app`)를 등록합니다.
  2. 같은 Wi-Fi 테스트 시에는 PC 방화벽에서 `3000` 포트가 허용되어 있는지 확인합니다.

### Q2. 카카오톡 공유 시 버튼이 안 보이거나 엉뚱한 주소로 이동함
- **원인**: 카카오 디벨로퍼스에서 도메인 등록이 누락됨.
- **조치**:
  1. **앱 설정 → 플랫폼 키 → JavaScript SDK 도메인**: 로컬 실행 주소(`http://localhost:3000`) 및 배포 주소 등록
  2. **제품 링크 관리 → 웹 도메인**: 카드 열람 도메인(`https://...vercel.app`) 등록

### Q3. 카카오톡 미리보기에 옛날 이미지가 계속 나옴
- **원인**: 카카오 서버의 링크/이미지 캐시 유지.
- **조치**: 이미지 URL 뒤에 버전 쿼리(`?v=2` 등)를 갱신하거나 카카오 디벨로퍼스 **도구 → 공유 디버거(캐시 초기화)** 로 캐시를 삭제합니다.

### Q4. Gmail / 네이버 메일 발송 실패
- **Gmail**: 일반 로그인 비밀번호가 아니라 Google 계정의 **2단계 인증 → 앱 비밀번호(16자리)** 를 입력해야 합니다.
- **네이버**: 네이버 메일 환경설정 → **POP3/IMAP 설정 → IMAP/SMTP 사용함** 활성화 후 `SMTP_FROM`을 본인 `@naver.com` 주소로 일치시켜야 합니다.

### Q5. Vercel 배포 시 `DATABASE_URL` 오류 또는 폰트 깨짐
- Vercel 환경변수에 `DATABASE_URL`(PostgreSQL)이 정확히 등록되어 있는지 확인하고, Build Command가 `package.json`의 `vercel-build`(`node scripts/prepare-prisma.mjs && npx prisma generate && next build`)를 실행하는지 점검합니다.
