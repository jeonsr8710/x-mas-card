## 2. 데이터베이스 모델 (`prisma`)

- **`Card`**: `id`, `slug`(12자 공개 URL 키), `manageToken`(22자 관리 권한 토큰), `templateId`, `senderName`, `title`, `message`, `bgmKey`, `customImageData`(Data URL 또는 `/samples/*.png`, 최대 1,600,000자), `createdAt`, `updatedAt`
- **`Delivery`**: `id`, `token`(10자 개인화 토큰 `?d=`), `cardId`, `recipientName`, `channel`(`EMAIL` | `KAKAO` | `SMS` | `LINK`), `targetAddress`(마스킹 저장), `status`(`READY` | `SENT` | `PREVIEW` | `FAILED`), `sentAt`, `openedAt`, `openCount`, `errorMessage`
- **`Reply`**: `id`, `cardId`, `authorName`, `emoji`, `content`, `createdAt`

## 3. 하이브리드 보안 및 개인정보 보호 구조

1. **공개 뷰어 격리 (`isPublicViewerOnly()` — [mode.ts](file:///home/jeonsr/바탕화면/Project/X-mas/src/lib/mode.ts))**:
   - `PUBLIC_VIEWER_ONLY="true"` 또는 Vercel 환경(`VERCEL="1"`, 명시적 `"false"`가 아닌 경우)에서 자동 활성화됩니다.
   - 활성화 시 `/`(제작 에디터), `GET/POST /api/cards`, `/manage/*`, `/api/manage/*`, `/api/settings` 가 모두 `403`/`404`로 차단되어 외부인은 `/c/[slug]` 열람 및 답장만 사용할 수 있습니다.
2. **발신자 인증정보 로컬 격리 ([settings.ts](file:///home/jeonsr/바탕화면/Project/X-mas/src/lib/settings.ts))**:
   - SMTP 비밀번호, Resend/Solapi/Kakao 키는 클라우드 PostgreSQL에 저장하지 않고 로컬 파일 `.xmas-settings.local.json`(권한 `0o600`)에만 보관합니다.
3. **수신자 연락처 마스킹 ([privacy.ts](file:///home/jeonsr/바탕화면/Project/X-mas/src/lib/privacy.ts))**:
   - 발송 직후 DB(`Delivery.targetAddress`)에는 `je***@gmail.com`, `010-****-5678` 형태로 마스킹된 값만 저장합니다.
4. **네트워크 Base URL 자동 승격 ([network.ts](file:///home/jeonsr/바탕화면/Project/X-mas/src/lib/network.ts))**:
   - 설정된 `baseUrl`이 비어 있거나 `localhost`인 상태에서 QR·문자 링크를 만들면, 서버가 자동으로 현재 PC의 사설 LAN IP(`192.168.x.x:3000`)를 감지해 같은 와이파이 내 스마트폰에서도 QR 스캔이 열리도록 변환합니다.
